## 1. 개요

### 1.1 페이지의 단 하나의 목적
**방문자가 무료 진단 신청 폼을 제출하게 하는 것.** 그 외 모든 요소(콘텐츠·디자인·인터랙션)는 이 단일 목적에 종속됩니다.

### 1.2 타겟 사용자
"디지털은 어렵지만 시간은 부족한 사장님". 직원 1~20명 규모 사업장 운영자. 카카오톡·문자에는 능숙하지만 새 SaaS를 직접 익혀 도입할 시간은 없는 분들.

### 1.3 사용자 여정 (4단계)
페이지를 처음 본 사장님은 다음 4단계를 거쳐야 신청에 도달합니다. 각 섹션은 이 중 하나의 단계를 책임집니다.

| 단계 | 사장님 마음속 질문 | 담당 섹션 |
|------|------------------|-----------|
| 1. **공감** | "내 얘기네" | Hero, Problem |
| 2. **이해** | "이게 뭐 하는 건데?" | Process, Industries |
| 3. **납득** | "나한테도 효과 있나?" | Calculator, Banner |
| 4. **행동** | "그래, 신청해보자" | Pricing, FAQ, Form |

### 1.4 성공 지표
- **1차 KPI**: 무료 진단 신청 폼 제출률 (방문자 대비 %)
- **2차 KPI**: 평균 체류 시간, 계산기 인터랙션 비율, 섹션별 도달률

### 2.2 각 섹션의 단일 목적

각 섹션은 **단 하나의 일**만 합니다. 여러 일을 하려는 섹션은 분리하거나 제거합니다.

| 섹션 | 단일 목적 | 출구 (다음 행동) |
|------|---------|----------------|
| Nav | 어디든 즉시 신청으로 이동 | 우측 CTA 클릭 |
| Hero | 첫 5초에 가치를 이해시킴 | 진단 신청 또는 계산기 |
| Trust Bar | "기존 도구 다 갈아엎나?" 우려 해소 | (스크롤 유도) |
| Problem | "내 얘기다" 공감 | (스크롤 유도) |
| Process | 작동 방식 명확화 | (스크롤 유도) |
| Industries | 자기 업종 발견 | (스크롤 유도) |
| Calculator | 개인화된 ROI 체험 | 진단 신청 |
| Banner | 신뢰의 결정타 | 진단 신청 |
| Pricing | 가격 투명성 | 진단 신청 |
| FAQ | 마지막 망설임 해소 | 진단 신청 |
| Form | 신청 완료 | 제출 |

## 3. 브랜드 시스템

### 3.1 브랜드 핵심
| 항목 | 내용 |
|------|------|
| 이름 | **OttO** (한글: 오토) |
| 의미 | "auto-"의 어원 + 친근한 사람 이름 |
| 한 줄 정의 | "사장님 옆자리에서 함께 일하는 AI 자동화 파트너" |
| 슬로건 | **"반복은 OttO에게."** |
| 보조 슬로건 | "사장님의 자동조종장치, OttO" |
| 톤 | 정밀하고 신뢰감 있되 따뜻함 (토스/Linear/Stripe 톤) |

### 3.2 로고

**구성**: 두 개의 원이 나란히 놓인 형태. 왼쪽 원은 검은 윤곽선만(사장님 = 본업), 오른쪽 원은 코발트 블루 채움(OttO = 자동화).

```
┌──────────────────────────────────┐
│  ◯ ●  OttO                       │  ← 가로형 (기본)
└──────────────────────────────────┘

   ◯ ●
   OttO                              ← 세로형 (예외)
```

**SVG 마크 사양**:
- viewBox: `0 0 28 28`
- 좌측 원: cx=9, cy=14, r=6, stroke=`#18181b`, stroke-width=2.2, fill=none
- 우측 원: cx=19, cy=14, r=6, fill=`#1d4ed8`
- 두 원 사이 간격: 4px (반지름 6 + 6 - 겹침 2 = 10, 중심 거리 10)

**워드마크 사양**:
- 폰트: Pretendard 800 (extra-bold)
- 크기: 19px (네비) / 17px (푸터)
- 자간: -0.04em
- 마지막 "O"는 메인 컬러(코발트 블루)

**최소 크기**: 마크 24px / 워드마크 14px (가독성 보장 한계)
**여백**: 로고 주변 최소 16px의 클리어스페이스

### 3.3 음성·톤 가이드

**해도 되는 것**
- 짧고 단호한 문장. "사장님은 두 번 일하지 않습니다."
- 사장님의 고됨을 인정. "혼자 하지 마세요."
- 구체적 숫자. "주 12시간 절감", "1~2주 셋업"
- 한국 비즈니스 어휘. "사장님", "가게", "직원", "본업"

**하지 말 것**
- 영어 마케팅 용어 남발 ("스케일링", "그로스 해킹")
- 과장 ("혁명", "최고", "유일한")
- 한정 모집/긴박감 압박 ("지금 안 하면 손해!")
- 기술 자랑 ("GPT-4 기반의 RAG 아키텍처")
- 학술적 어조 ("귀하의 사업체를 위한 솔루션")

### 4.2 타이포그래피

#### 폰트 패밀리

| 토큰 | 값 | 용도 |
|------|------|------|
| `--sans` | Pretendard Variable, Inter, system-ui | 모든 텍스트 (한국어 + 영문 통합) |
| `--mono` | JetBrains Mono | 숫자·라벨·코드 강조 |

> **세리프 폰트는 사용하지 않습니다.** 위계는 굵기(weight)와 크기로만 표현합니다. 이게 토스/Linear/Stripe 톤의 핵심입니다.

#### 크기 스케일

| 용도 | 크기 | 굵기 | 자간 | 행간 |
|------|------|------|------|------|
| Hero H1 | clamp(44px, 6.5vw, 76px) | 800 | -0.045em | 0.98 |
| Section H2 | clamp(32px, 4.2vw, 48px) | 800 | -0.035em | 1.05 |
| Card H3 | 22px (대형) / 17px (소형) | 700 | -0.025em | 1.2 |
| Body Large | 18px | 400 | -0.011em | 1.6 |
| Body | 15px | 400 | -0.011em | 1.55 |
| Body Small | 13.5px | 500 | -0.011em | 1.5 |
| Caption | 12px | 500 | 0.05em (mono는 0.08em) | 1.4 |
| Display Number (큰 숫자) | clamp(56px, 9vw, 96px) | 800 | -0.045em | 0.95 |

#### 폰트 굵기 사용 원칙

- **400** (Regular): 일반 본문
- **500** (Medium): 라벨, 보조 텍스트, 메뉴
- **600** (Semibold): 강조 텍스트, 작은 헤더, 버튼
- **700** (Bold): 카드 제목, 중간 헤더
- **800** (Extra-bold): 헤드라인, 큰 숫자, 가격

> **굵기 점프 원칙**: 500 → 600 → 800 순으로만 사용. 600 → 700 같은 작은 점프는 시각적 차이가 약해 위계가 흐려집니다.

### 4.3 간격(Spacing) 시스템

8px 기반 스케일을 따릅니다.

| 토큰 | 값 | 용도 |
|------|------|------|
| xs | 4px | 인라인 요소 사이 |
| sm | 8px | 라벨-입력 사이, 작은 갭 |
| md | 16px | 카드 내부 여백 (작은 카드) |
| lg | 24px | 카드 내부 여백 (기본) |
| xl | 32px | 카드 내부 여백 (큰 카드) |
| 2xl | 48px | 섹션 내 큰 갭 |
| 3xl | 64px | 좌우 컬럼 사이 갭 |
| 4xl | 96px | 섹션 사이 (section padding) |

**컨테이너**: 최대 너비 `1200px`, 좌우 패딩 `24px`.

### 4.4 그림자 (Elevation)

3단계 layered shadow 시스템. 단순 drop-shadow가 아니라 1px 라이트 라인을 함께 깔아서 종이 같은 깊이감을 줍니다.

| 토큰 | 값 | 용도 |
|------|------|------|
| `--shadow-sm` | `0 1px 2px rgba(24,24,27,0.04), 0 1px 3px rgba(24,24,27,0.06)` | 미세한 elevation |
| `--shadow-md` | `0 4px 6px -1px rgba(24,24,27,0.04), 0 12px 24px -8px rgba(24,24,27,0.08)` | 카드 호버 |
| `--shadow-lg` | `0 1px 0 rgba(24,24,27,0.04), 0 24px 48px -16px rgba(24,24,27,0.16)` | 메인 모달, 히어로 모형 |

### 4.5 보더 라디우스

| 용도 | 값 |
|------|------|
| 작은 요소 (배지, 칩, 작은 버튼) | 6~8px |
| 일반 (입력, 버튼) | 8~10px |
| 카드 (작은) | 12px |
| 카드 (기본) | 14~16px |
| 큰 컨테이너 | 24px |
| 원형 (점, 펄스, 아이콘 컨테이너) | 50% 또는 999px |

### 4.6 전환 (Transition)

| 용도 | 값 |
|------|------|
| 색상·배경 변화 | `0.15s ease` |
| 변형(transform), 그림자 | `0.2s ease` |
| 큰 요소 부드러운 등장 | `0.6s ease` |
| 펄스 애니메이션 | `2s ease-in-out infinite` |

### 4.7 배경 효과

#### Mesh Gradient (히어로 영역 상단)
```css
body::before {
  position: fixed;
  top: 0; left: 0; right: 0;
  height: 700px;
  background:
    radial-gradient(ellipse 80% 50% at 20% 0%, rgba(29, 78, 216, 0.06), transparent 60%),
    radial-gradient(ellipse 60% 40% at 80% 10%, rgba(96, 165, 250, 0.05), transparent 60%);
}
```
이게 Stripe·Linear의 핵심 시그니처. **거의 안 보일 정도로 미세하게** 깔립니다.

#### 다크 배경 글로우 (계산기 결과·배너)
```css
::before {
  background: radial-gradient(circle, rgba(59, 130, 246, 0.35), transparent 60%);
  width: 300~500px; height: 동일;
  position: absolute (카드 외곽으로 살짝 빠져나감);
}
```

```
  보더 색상만 #18181b으로 변경
```

```svg
<svg width="14" height="14" viewBox="0 0 14 14" fill="none">
  <path d="M3 7H11M11 7L7 3M11 7L7 11"
    stroke="currentColor" stroke-width="1.6"
    stroke-linecap="round" stroke-linejoin="round"/>
</svg>
```

### 5.2 입력 필드

## 8. 모션·애니메이션

### 8.1 페이지 진입 (Reveal on Scroll)

```javascript
const observer = new IntersectionObserver(entries => {
  entries.forEach(e => {
    if (e.isIntersecting) {
      e.target.classList.add('visible');
      observer.unobserve(e.target);
    }
  });
}, { threshold: 0.1 });
```

```css
.reveal {
  opacity: 0;
  transform: translateY(16px);
  transition: opacity 0.6s ease, transform 0.6s ease;
}
.reveal.visible { opacity: 1; transform: translateY(0); }
```

Hero 안 요소들은 진입 시 100ms 간격으로 순차 등장.

### 8.2 펄스 애니메이션 (Live 표시 점)

```css
@keyframes pulse {
  0%, 100% { opacity: 1; transform: scale(1); }
  50% { opacity: 0.4; transform: scale(0.7); }
}
.dot { animation: pulse 2s ease-in-out infinite; }
```

빠른 펄스(1.5s)는 강조용, 느린 펄스(2s)는 일반용.
