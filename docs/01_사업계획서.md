# OttO — AI 업무 자동화 구독 서비스 사업계획서

> **한 줄 정의**: 소상공인·학원·중소사업장의 반복 업무를 진단하고, AI와 맞춤 프로그램으로 자동화해주는 **B2B SaaS + 컨설팅 하이브리드** 서비스.

> **브랜드 약속**: "반복은 OttO에게, 본업은 사장님께."

---

## 1. 브랜드 정체성

### 1.1 OttO라는 이름
"Otto"는 자동화를 뜻하는 영어 접두어 **"auto-"** 의 어원이며, 동시에 친근한 사람 이름이기도 합니다. 두 개의 대문자 O가 만드는 시각적 균형은 **"입력 → 처리 → 출력"** 의 자동화 사이클을 상징합니다. 이 점에서 OttO는 단순한 도구가 아니라 **사장님 곁에서 일하는 AI 직원**의 의미를 내포합니다.

### 1.2 핵심 가치 제안
"SaaS 한 개 가입하고 끝나는 게 아닙니다. 가게에 맞게 분석·구축·운영까지 풀 사이클로 책임지는 AI 자동화 파트너."

### 1.3 슬로건 후보
- 메인: **"반복은 OttO에게."**
- 서브: "사장님의 자동조종장치, OttO"
- 보조 카피: "AI가 지키는 사장님의 시간"

### 1.4 차별점
일반 SaaS는 "기능"을 팔지만, OttO는 **"문제 진단 → 맞춤 자동화 구축 → 지속 운영"** 의 풀 사이클을 제공합니다. 사장님은 도구를 직접 고를 필요도, 조합할 필요도, 유지보수할 필요도 없습니다.

## 2. 시장과 타겟

### 2.1 한국 시장 규모
한국에는 약 **660만 명의 소상공인·자영업자**, **8만 개의 학원**, **770만 개의 중소사업장**이 있습니다. 이들 대부분은 다음과 같은 공통점을 가집니다.

- 인력 부족으로 사장이 행정·운영·마케팅을 모두 떠안음
- 엑셀·카카오톡·종이장부에 의존하는 비효율 워크플로우
- "AI 도입하고 싶지만 어디서부터 해야 할지 모름"
- 월 5~30만 원 구독료에는 비교적 관대 (이미 여러 SaaS 사용 중)

### 2.2 타겟 페르소나
**"디지털은 어렵지만 시간은 부족한 사장님"** 이 핵심 타겟입니다. 직원 1~20명 규모의 사업장으로, 카카오톡과 문자메시지는 능숙하지만 새 SaaS를 직접 익혀 도입할 시간은 없는 분들입니다. 이분들에게는 **"도구 가입"** 이 아니라 **"대신 해드림"** 이 작동합니다.

### 2.3 진입 전략 — 버티컬 록인 없이 시작
첫 진입 버티컬을 미리 정하지 않습니다. 대신 **"먼저 연락 주신 사장님부터 진단·구축"** 으로 시작하여, 셋업 결과를 그대로 모듈 라이브러리에 적립합니다. 이후 같은 업종의 두 번째 고객은 50% 이상 빠른 시간에 셋업 가능합니다. 즉, **"한 명의 고객이 다음 고객의 비용을 낮춘다"** 는 구조를 만듭니다.

### 2.4 초기 14개 타겟 업종
학원·교습소, 병의원·클리닉, 음식점·카페, 미용실·뷰티, 헬스장·필라테스, 부동산 중개, 법무·세무·회계, 펜션·숙박, 자동차 정비소, 인테리어·시공, 동물병원·펫샵, 소매·온라인몰, 꽃집·케이크샵, 1인 사장·프리랜서. 위 14개 외 업종도 진단 시 맞춤 설계 가능.

## 3. 서비스 구조

### 3.1 3단계 풀 사이클

| 단계 | 명칭 | 내용 | 과금 |
|------|------|------|------|
| **STEP 01** | 무료 진단 | 30분 인터뷰 + 업무 흐름 분석 + 자동화 가능성 리포트 | 무료 |
| **STEP 02** | 맞춤 셋업 | 자동화 모듈 구축, 데이터 이전, 직원 1회 교육 | 일회성 셋업비 |
| **STEP 03** | 월 구독 운영 | 동작 점검, 신규 모듈 추가, 우선 지원 | 월 구독료 |

### 3.2 자동화 모듈 카테고리 (80+ 모듈)
공통 패턴을 묶어 **"모듈 라이브러리"** 로 운영합니다. 신규 고객은 라이브러리에서 모듈을 조합 + 약간의 커스터마이징으로 빠르게 셋업합니다.

- **고객 응대**: 카톡 챗봇, FAQ 자동 응답, 음성 AI 응대, 다국어 번역
- **알림 자동화**: 출결·예약·기념일·정기 결제 카톡 알림
- **문서 자동화**: 청구서·견적서·계약서·영수증 자동 생성·발송
- **마케팅**: 블로그·인스타·당근 콘텐츠 AI 작성, 리뷰 자동 응답
- **데이터·리포트**: 매출 분석, 고객 행동 분석, 주간/월간 리포트
- **운영**: 직원 스케줄, 재고 발주, 예약 통합 관리, 노쇼 방지

## 4. 비즈니스 모델

### 4.1 요금 체계

| 플랜 | 월 구독료 | 셋업비 | 대상 |
|------|----------|--------|------|
| **Starter** | 9.9만 원 | 50만 원 | 1인 사장·소형 가게 |
| **Pro** | 29.9만 원 | 100만 원 | 직원 5~20명·중형 사업장 |
| **Business** | 69.9만 원~ | 협의 | 다지점·중견 사업장 |

### 4.2 구조 설계 원리
**셋업비(일회성) + 월 구독료(반복)** 의 하이브리드입니다. 셋업비는 (1) 진입 장벽으로 작용하여 단순 호기심 고객을 거르고, (2) 초기 현금흐름을 만들며, (3) 셋업 작업의 실제 인건비를 보전합니다. 월 구독료는 LTV의 핵심으로, 무약정 월 단위지만 자동화에 의존하게 되면 자연스럽게 락인됩니다.

### 4.3 창업 멤버 프로그램
첫 10팀에게는 다음 혜택을 제공합니다. 이는 단순 할인이 아니라 **"공동 개발"** 컨셉입니다.

- 셋업비 50% 할인 (100만 → 50만 원)
- 첫 6개월 구독료 50% 할인 (29.9만 → 14.9만 원)
- 평생 30% 락인 할인 (해지 후 재가입에도 적용)
- 대표 직접 전담 매니저
- 자동화 모듈 무제한 추가
- **대신**: 사례 공개 동의(가게명 비공개 가능), 분기 1회 30분 피드백 인터뷰 협조

### 4.4 단위 경제성

| 지표 | 가정 값 |
|------|---------|
| 평균 월 ARPU | 25만 원 |
| 평균 유지 기간 | 24개월 |
| 평균 LTV | 600만 원 (구독) + 75만 원 (셋업비) = **675만 원** |
| CAC 목표 | 30~50만 원 |
| LTV/CAC 목표 | **13배 이상** |
| 손익분기 도달 고객 수 | 80~120 (1인 운영 기준) |

## 5. 운영 모델

### 5.1 1인 운영 시 시간 배분
영업·진단 40%, 셋업·구축 30%, 콘텐츠 마케팅 20%, 고객 지원 10%. 개발은 가능한 한 **노코드 + AI API + 외주** 조합으로 충당합니다.

### 5.2 자동화의 자동화 — OttO 자체 운영도 자동화
OttO 자신도 OttO 도구로 운영합니다. 진단 신청 → 자동 일정 조율 → 인터뷰 녹음 → AI 요약 리포트 → 후속 메일·카톡까지 모두 자동화. 이를 통해 1인 운영 가능 고객 수를 크게 늘립니다.

### 5.3 채용 계획

| 시점 | 포지션 | 역할 |
|------|--------|------|
| 0~6개월 | 1인 (대표) | 영업 · 셋업 · 지원 전부 |
| 6~9개월 | 셋업 엔지니어 | n8n·API 연동 셋업 담당 |
| 9~12개월 | CS·운영 매니저 | 고객 응대·재구성 담당 |
| 12개월~ | 백엔드 개발자 | 자체 모듈 고도화 |

## 6. 마케팅·영업 전략

### 6.1 채널별 전략
**1차 채널 (0~3개월) — 직접 영업 + 카페 홍보**
소상공인 카페(네이버·카카오 오픈채팅·당근)에 "창업 멤버 모집" 글로 진입합니다. 자랑이 아닌 **도움 요청 톤**으로 접근하며, "10팀 한정 50% 할인 대신 솔직한 피드백"을 교환 조건으로 제시합니다.

**2차 채널 (3~6개월) — 사례 콘텐츠 마케팅**
첫 시범 고객들의 절감 시간·매출 변화를 콘텐츠화합니다. "학원 원장이 1주일에 12시간 아끼는 법" 같은 실용 시리즈를 블로그·유튜브 쇼츠·인스타 릴스로 발행. 자체 운영하던 자동화를 그대로 콘텐츠화하므로 제작 비용이 적습니다.

**3차 채널 (6~12개월) — 파트너십**
세무사·노무사·학원 컨설팅·인테리어 업자 등 사장님들을 자주 만나는 직군과 제휴. 그들이 OttO를 추천하면 일정 비율 수수료를 지급하는 구조.

**4차 채널 (12개월~) — 유료 광고**
LTV/CAC가 검증된 후에만 시작. 메타·구글·네이버 광고로 검증된 페르소나를 타깃.

### 6.2 입소문 설계
한 명의 만족 고객이 같은 업종의 다른 사장님을 데려오는 구조가 핵심입니다. 이를 위해 **추천 보상 프로그램**(추천 시 양쪽 모두 1개월 무료)을 도입합니다.

## 7. 12개월 로드맵

### Phase 1 — 검증 (0~3개월)
- 랜딩 페이지 + 신청 폼 오픈
- 소상공인 카페 5곳 홍보 진입

- 가장 효과 큰 자동화 모듈 5~7개 확정
- 셋업 SOP(표준 운영 절차) 1차 문서화

### Phase 2 — 정식 런칭 (4~6개월)
- 정식 가격 정책으로 첫 유료 고객 10팀 확보
- 추천 보상 프로그램 가동
- 사례 콘텐츠 발행 (월 4회 이상)
- 모듈 라이브러리 20개 이상으로 확장

### Phase 3 — 확장 (7~9개월)
- 누적 고객 30~50팀
- 셋업 엔지니어 1명 채용
- 진단·셋업 자동화 비율 50% 이상
- 첫 파트너십 계약 (세무사·노무사 등)

### Phase 4 — 두 번째 버티컬 (10~12개월)
- 누적 고객 100팀, MRR 2,500만 원 목표
- 가장 성과 좋은 단일 업종에 집중하는 두 번째 브랜드 페이지 런칭
- CS·운영 매니저 1명 채용

## 9. 리스크와 대응

가장 큰 리스크는 **"고객마다 요구가 달라 셋업이 무한정 길어지는 것"** 입니다. 이를 막기 위해 셋업 범위를 계약서에 명시하고, 범위를 넘는 커스터마이징은 별도 견적으로 처리합니다.

두 번째 리스크는 **AI API 비용 급증**입니다. 사용량이 많은 고객에게는 사용량 기반 추가 과금 조항을 두고, 자체 캐싱·요약 압축으로 토큰 비용을 관리합니다.

세 번째 리스크는 **"기존 SaaS와의 기능 경쟁"** 입니다. OttO는 기능 경쟁을 하지 않습니다. **"맞춤화 + 한국형 업무 흐름 + 직접 지원"** 으로 차별화하며, 도구가 아닌 **결과(시간 절감)** 를 판매한다는 메시지를 일관되게 유지합니다.

네 번째 리스크는 **1인 운영의 번아웃**입니다. 처음부터 OttO 자신의 운영도 자동화하고, 셋업 SOP를 문서화하여 언제든 외주·채용으로 분담 가능한 구조를 만듭니다.
